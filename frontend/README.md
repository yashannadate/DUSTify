# 🖥️ @dustify/frontend — DUSTify Developer Dashboard & Explorer

React 18 + Vite 5 + Tailwind CSS developer dashboard for testing and monitoring DUSTify gasless transactions.

---

## ✨ Features

- **Minimalist Monochrome Dark Aesthetics:** Fast, responsive, high-contrast UI.
- **4 Dedicated Views:** Overview, Gasless Demo, Relayer Telemetry, and Documentation.
- **Interactive Contract Simulation:** Live execution testing for `hello-world.compact` and `Voting.compact`.
- **Live Telemetry:** Real-time polling of Midnight Preview indexer sync and DUST capacity.

---

## 🏃 Run Locally

```powershell
# In PowerShell / Windows / Linux:
npm run dev
```
*Opens on [http://localhost:5173](http://localhost:5173)*
